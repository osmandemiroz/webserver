BIM308 – Web Server Programming – 4th Assignment 
 
In this homework, you will develop a University Information System using a RESTful API. This system 
will include key components such as Students, Courses, and Classrooms. The API will facilitate 
interaction between these components using HTTP methods (GET, POST, PUT, DELETE).

2. System Relationships (Conceptual) 
• A Book belongs to an Author 
• A User can rent multiple Books 
• rentedBookIDs field represents the books borrowed by users

4. Technical Requirements 
• RESTful API principles must be followed 
• Proper HTTP status codes should be used (200, 201, 404, 400, etc.) 
• JSON format must be used for request/response 
• Layered architecture is recommended: 
o Controller 
o Service 
o Repository (optional)
